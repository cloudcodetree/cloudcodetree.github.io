## See every request: tracing

You can't debug what you can't see. **Langfuse** (or LangSmith/OpenTelemetry) records a trace per request — each tool call, token count, latency, and cost — so a slow or wrong answer is a span you can open, not a mystery. Wrap your agent/LLM calls and every run becomes inspectable.

## Know what it costs: FinOps

LLM bills surprise teams because cost is invisible until the invoice. Attribute every call to a model (and feature), total it, and alert as you approach budget:

<CostDashboard />

```python
# dealfinder/ops.py
class CostTracker:
    def record(self, model, in_tok, out_tok):
        p_in, p_out = PRICES[model]
        cost = (in_tok * p_in + out_tok * p_out) / 1e6
        self.calls.append({"model": model, "cost": cost}); return cost

budget_status(spent=88, budget=100)   # → "warn" at 80%+
```

Cost attribution is what lets you answer "which feature is burning the budget?" — and act (cache it, shrink the model, batch it) before finance asks.

## Catch decay: drift detection

A model is trained on a snapshot of the world; the world moves. If buyers shift toward premium tents, the price model's assumptions go stale and deal scores rot — silently. A **population stability index (PSI)** compares this week's input distribution to the training baseline and flags significant drift:

<DriftMonitor />

```python
def has_drifted(ref, cur, threshold=0.2):     # PSI > 0.2 = significant drift
    return population_stability_index(ref, cur) >= threshold
```

When PSI trips, you trigger the **retrain** job — orchestrated (Airflow/Prefect), evaluated against the champion (Part 11), and promoted only on a win. That's the full MLOps loop closing on itself.

<Callout tone="note">
**How this scales in production.** Ship traces to Langfuse with dashboards and alerting (PagerDuty/Slack), break cost down by model, feature, and customer, set per-team budgets, monitor drift per feature on a schedule, and wire drift/eval regressions to an **orchestrated retrain → eval → canary** pipeline. Observability isn't an add-on — it's how the system stays correct after launch.
</Callout>

# Code Compare

A small tool for viewing different programming languages' syntax side by side —
how the same construct (a loop, a class, a map/filter) reads across languages,
on one screen.

It's an early, simple project kept here honestly: a static HTML/JavaScript
page, useful as a quick reference, with no build step and no dependencies.

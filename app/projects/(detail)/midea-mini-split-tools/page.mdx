# Midea Mini-Split Tools

A toolkit for controlling **Senville** (and other Midea-OEM) ceiling cassette
mini-splits from **Home Assistant** — both the preferred wired-control path and
a working IR-based fallback. Built and validated against real hardware
(SENA-09IC-Z and SENA-18HF-ICZ cassettes); the protocols apply to most
Midea-derived brands, which share the same XYE/CCM RS-485 bus and IR remote
families.

## Two subprojects

**`esp32-controller/` — ESPHome XYE bridge (wired).** ESP32 firmware bridging
the cassette's RS-485 bus to Home Assistant. Bidirectional: HA gets a real
`climate.*` entity plus diagnostic sensors (coil temps, error/protect flags,
defrost). WiFi + native HA API + OTA; works without HA via a built-in web UI.
Silent — no IR, no beeps.

**`follow-me-ir/` — Follow Me IR encoder.** A from-scratch, reverse-engineered
Python encoder for Midea's "Follow Me" IR transmissions, output as Broadlink
Base64 commands. It exists because Senville cassettes ignore the XYE
`follow_me_sensor` field for control decisions — so this fires real Follow Me
pulses from HA with room temperature sourced from any real sensor. Result: the
cassette controls to sitting-height room temperature instead of a ceiling-sensor
bias that typically runs 3–5 °F off.

- **675 pre-encoded codes** covering every (sensor temp, setpoint) pair
- **Validated bit-for-bit** against captured remote transmissions
- Includes a decoder for diffing captures during protocol work

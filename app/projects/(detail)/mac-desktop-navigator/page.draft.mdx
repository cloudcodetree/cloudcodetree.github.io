# Desktop Navigator

A native macOS menu bar utility for switching between Mission Control Spaces,
launching Mission Control, and capturing screenshots — one unobtrusive row of
icons in the menu bar.

## Features

- **Clickable rectangles** — one per desktop, the current one filled; click to switch
- **Screenshot button** — starts macOS's selectable-area capture, straight to the clipboard
- **Mission Control button** — opens the overview
- **Auto-heal** — add desktops and the rectangles + shortcuts appear automatically
- **Auto-launch** — runs at login via a `launchd` LaunchAgent

## How it works

Pure Swift against AppKit. Switching synthesizes the `Ctrl+N` keystroke (which
is why macOS asks for Accessibility permission once). The install script
builds a release binary, assembles and signs a `.app` bundle — creating a
self-signed identity if you don't have a Developer ID — and registers the
LaunchAgent.

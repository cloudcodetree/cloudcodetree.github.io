**What each session record includes:**
- Full prompt and response text
- Tool call content: web browsing, MCP connector calls, skill runs, artifacts
- Metadata: verified user ID, organization ID, session and per-message IDs, timestamps

**Current beta scope:** Claude Code CLI and desktop app; Cowork desktop, web, and mobile. Not yet covered: Claude Code on the web, API-accessed Claude Code, or sessions on Bedrock, Vertex AI, or Foundry.

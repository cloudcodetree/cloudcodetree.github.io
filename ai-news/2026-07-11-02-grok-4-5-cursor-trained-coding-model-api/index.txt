According to xAI, it exceeds comparable frontier models on real engineering tasks with both intelligent and efficient reasoning.

**Pricing**: $2/MTok input, $6/MTok output — undercutting Sonnet-tier pricing while claiming Opus-class performance. For teams routing agentic coding tasks through OpenRouter or a custom API client, Grok 4.5 is a legitimate benchmark target.

**Why it matters:** The Cursor acquisition gave xAI training data that's unusually well-matched to how developers actually use code models. A $2 input price at Opus-class quality changes the economics for agentic loops that currently use Opus. Run your task distribution against it before committing.

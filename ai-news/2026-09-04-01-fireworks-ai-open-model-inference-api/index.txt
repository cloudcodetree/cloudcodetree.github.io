12:T918,**TL;DR: Fireworks AI exposes 250+ open-weight models (Llama 4, Qwen 3.7, DeepSeek V4) behind an OpenAI-compatible endpoint — change one URL and one model string, the rest of your pipeline stays the same.**

**What you'll be able to do after this:** route any prompt through Llama 4, Qwen 3.7, or DeepSeek without rewriting your pipeline, switch models by changing a string, and run cost-sensitive tasks on a model at $0.30/MTok instead of $2/MTok.

**Three things to know first:**
- Fireworks claims its disaggregated prefill/decode architecture reduces latency on large models — per Fireworks' own benchmarks; verify with your specific payload before committing production traffic.
- Free accounts start with a low requests-per-minute ceiling. Adding a payment method raises it, but both per-account and per-model token-per-minute limits apply — plan for rate-limit retries in production.
- The API is compatible with the OpenAI Python SDK and, via `base_url`, with the Anthropic SDK.

**Setup (3 steps):**

1. Get an API key at `fireworks.ai` (free tier works for testing).
2. `pip install openai` if you don't have it.
3. Swap the base URL:

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_FIREWORKS_KEY",
    base_url="https://api.fireworks.ai/inference/v1",
)

response = client.chat.completions.create(
    model="accounts/fireworks/models/llama-4-maverick-instruct",
    messages=[{"role": "user", "content": "Summarize this PR diff in two sentences."}],
)
print(response.choices[0].message.content)
```

Model IDs follow the pattern `accounts/fireworks/models/<slug>`. Find the full catalog at `fireworks.ai/models`.

**Limit:** Fireworks' performance figures come from Fireworks itself. There are no published independent benchmarks covering the full 250+ model catalog as of this writing. Measure your p50/p95 on your actual payload before treating their latency numbers as facts. For very short prompts with many concurrent requests, check whether per-model token-per-minute limits become the real bottleneck before blaming latency.

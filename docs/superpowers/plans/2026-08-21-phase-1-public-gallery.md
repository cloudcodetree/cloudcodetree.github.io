# Phase 1 — Public Projects Gallery: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the public half of the Projects section — `/projects` gallery, `/projects/<slug>` detail pages, nav entry — on the staging Worker, leaving cloudcodetree.com untouched.

**Architecture:** Mirror the tutorials subsystem exactly: a hand-maintained TypeScript manifest as single source of truth, a list component in the site's glass-card idiom, MDX detail pages under a route group, feeds/sitemap integration via the existing generate-feeds prebuild. No auth, no demos served — `demo.status: 'coming-soon'` renders a disabled affordance; the gate is Phase 2.

**Tech Stack:** Next.js 15 static export, MUI v7 dark theme, @next/mdx, existing vitest harness.

**Spec:** `docs/superpowers/specs/2026-08-20-projects-gated-demos-design.md`

## Global Constraints

- cloudcodetree.com untouched; deploys go to `cct-site-staging` only.
- Copy grounded in the real repos/READMEs fetched 2026-08-21 (scratchpad `readme-*.md`); no invented capabilities. `homestead-finder` is **private** → card without repo link (spec rule).
- **Deviation from spec, deliberate:** hero covers are committed build assets generated by script (the tutorials precedent), NOT R2 URLs. R2 (`cct-media` via `infra/r2.tf`) enters when real screenshots/recordings exist — no media exists yet, so creating the bucket now would be codifying nothing. Spec's media section otherwise stands.
- Tutorial companion repos stay out of the gallery (spec rule).
- Nav hrefs gain trailing slashes site-wide while the nav arrays are being edited (kills the per-click 307 hop found in Phase 0).
- Every task ends with `pnpm test` green + `pnpm run lint` green; commit per task.

### Task 1: Manifest + reader + tests
Files: `app/projects/manifest.ts`, `scripts/lib/projects-data.mjs`, `scripts/projects-data.test.mjs`.
Interface produced: `Project` type per spec (`slug,title,summary,tech[],repoUrl?,externalUrl?,demo?,cover,featured?,order?`; `media?` omitted until R2 exists) + `readProjects()` mjs reader mirroring `tutorials-data.mjs`. Test: reader returns all 8 slugs in order, homestead-finder has no repoUrl, span-calculator demo status is 'coming-soon'.

### Task 2: Gallery UI — `/projects`
Files: `app/components/ProjectsList.tsx` (+`ProjectCard`), `app/projects/page.tsx` (metadata export + server wrapper). Mirror `TutorialsList.tsx` idiom: glass cards, tech-chip filter, cards/list toggle if cheap. Rewrite replaces `ProjectsPage.tsx` usage; delete `featuredProjects` + GitHub API fetch. Verify: `wrangler dev`, browser screenshot, zero console errors.

### Task 3: Detail pages — `/projects/<slug>`
Files: `app/projects/(detail)/layout.tsx` (mirror `app/tutorials/(article)/layout.tsx`), 8 × `app/projects/(detail)/<slug>/page.mdx` with per-page `metadata`. Content from READMEs: what it is, why it exists, how it works, tech, links (repo/external), "demo coming soon" note where applicable. Honest lean page for code_compare.

### Task 4: Covers
Files: `scripts/generate-project-covers.mjs` (adapt `generate-tutorial-covers.mjs` via `projects-data.mjs`), committed output `public/projects/covers/<slug>.png`. Manifest `cover` points at these paths.

### Task 5: Nav + trailing slashes
Files: `app/components/ClientLayout.tsx` — nav becomes AI News · Tutorials · Projects · About; all nav/footer hrefs get trailing slashes. Grep-verify no bare internal hrefs remain in nav arrays.

### Task 6: Feeds/sitemap/robots + parity case
Files: `scripts/generate-feeds.mjs` (add `/projects/` + per-slug URLs to sitemap via `readProjects()`), `public/robots.txt` (Allow /projects), `scripts/check-parity.mjs` (add `/projects/` contract case — staging-only until cutover: guard on origin or accept 404 on prod until Phase 3... simplest: add case only after prod ships; instead assert on staging via sweep, which picks up sitemap automatically). Decision recorded: no prod-breaking contract case; sweep covers it.

### Task 7: Deploy + verify + evidence
`pnpm run build:staging && wrangler deploy --env staging`; browser pass over gallery + 2 detail pages; parity contract + sweep against staging; append results to the Phase 1 section of a new evidence file.

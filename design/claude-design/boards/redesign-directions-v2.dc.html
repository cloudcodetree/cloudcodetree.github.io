PostToolUse Fires Even When the Model Won’t

Add deterministic side-effects to every Claude Code session — formatting, checkpoint commits, and test runs that happen outside model control.

Author Chris Harper
Published 2026-08-03 12:07 UTC

The critical property of Claude Code hooks is that they run outside the model’s decision loop. When PostToolUse fires after a Write call, the model can’t skip it, defer it, or decide it’s unnecessary.

How the hook receives its input

Every hook gets a JSON payload on stdin. For PostToolUse after a Write, the relevant fields are the file just written and the tool’s result.

#!/usr/bin/env bash set -euo pipefail npx prettier --write "$fp"

That gap between “the model might do X” and “X will always happen” is the key to reliable workflows.
